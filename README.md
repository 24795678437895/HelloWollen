# Ҳарбий самолёт симулятори — Unity / Android

Android учун Unity 3D аркада-симулятор прототипи. Одоогийн хувилбар нь самолётни бошқариш, газ/тормоз, шасси, ташқи ва кокпит камераси, HUD, машқ нишонлари ва ўқ узишни ўз ичига олади. Самолёт ва муҳит ҳозирча Unity примитив объектларидан тузилган; бу ҳақиқий авиация тренажёри эмас.

## Unity'да очиш ва ишга тушириш

1. Unity Hub'да ушбу репозиторий папкасини лойиҳа сифатида очинг. Unity версияси `ProjectSettings/ProjectVersion.txt` да кўрсатилган.
2. Unity муҳарририда `Tools > Flight Simulator > Create Demo Scene` ни танланг. Саҳна `Assets/Scenes/FlightDemo.unity` сифатида яратилади.
3. `FlightDemo` саҳнасини очиб, Play тугмасини босинг.

## Android APK тузиш

1. Unity Hub орқали лойиҳанинг Unity версиясига мос **Android Build Support**, **Android SDK & NDK Tools** ва **OpenJDK** модулларини ўрнатинг.
2. `File > Build Settings > Android > Switch Platform` ни босинг.
3. Build Settings'да `Assets/Scenes/FlightDemo.unity` саҳнаси рўйхатда борлигини текширинг.
4. `Build` ёки телефонда синаш учун `Build And Run` ни танланг. APK чиқариш учун `Build` тугмасини босинг.

Бу репозиторий APK бинарини ўз ичига олмайди; APK Unity муҳарририда Android модуллари билан тузилади.

## Бошқарув

- **Телефон:** чап томондаги сенсорли майдон самолётни буриш ва кўтариш/пастлатишга хизмат қилади. Ўнгдаги тугмалар газни оширади/камайтиради, шассини бошқаради, камерани алмаштиради ва ўқ узади. Тормоз тугмасини босиб туринг.
- **Компьютер синови:** `W/S` — кўтарилиш/пастлаш; `A/D` — эгилиш; `Q/E` — йў��алиш; `Shift/Ctrl` — газ; `B` — тормоз; `Space` — ўқ узиш; `G` — шасси; `C` — камера.
- Нишонга тегилганда 100 очко берилади.

## Тузилиши

- `Assets/Scripts/` — учиш физикаси, камера, HUD, нишон ва ўқ механикаси.
- `Assets/Editor/` — демо саҳнани яратиш менюси.
- `ProjectSettings/`, `Packages/` — Unity лойиҳа ва пакет созламалари.

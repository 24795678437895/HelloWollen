# Ҳарбий самолёт симулятори (Unity / Android)

Android телефонлари учун Unity 3D ҳарбий самолёт симуляторининг бошланғич прототипи. Унда самолёт физикаси, сенсорли бошқарув, газ ва тормоз, шасси, ташқи/кокпит камераси, HUD, нишонлар ва ўқ узиш мавжуд. Ҳозирча самолёт ва муҳит примитив шакллардан йиғилади; тайёр 3D моделлар киритилмаган.

## Unity'да ишга тушириш

1. Unity Hub'да 3D Core лойиҳаси очинг (Unity 2022.3 LTS ёки янгироғи тавсия қилинади).
2. Бу репозиторийдаги `Assets/Scripts` папкасини лойиҳангиздаги `Assets/Scripts` ичига кўчиринг.
3. Янги саҳнада бўш `GameObject` яратиб, унга `FlightGameBootstrap` компонентни қўшинг.
4. Саҳнани сақланг ва Play босинг. Прототип самолёт, учиш йўлаги, нишонлар, камера ва бошқарув интерфейсини ўзи яратади.
5. Android руугарагт: `File > Build Settings > Android > Switch Platform`; `Player Settings`-д `Active Input Handling`-ни `Both` ёки `Input Manager (Old)` қилинг. Қурилмада синаш учун USB debugging ёқилган телефонни уланг.

## Бошқарув

- **Телефон:** чап пастдаги виртуал джойстик — бурилиш/кўтарилиш; ўнг томондаги тугмалар — газ, тормоз, шасси, камера ва ўқ узиш.
- **Компьютерда синов:** `W/S` — кўтарилиш/пастлаш, `A/D` — эгилиш, `Q/E` — йўналиш, `Shift/Ctrl` — газ, `Space` — ўқ узиш, `G` — шасси, `C` — камера.
- Нишонга ўқ тегса у йўқолади ва очко нэмэгдэнэ. Прототипт дайсны AI, миссиялар, аутентик самолёт моделлари ва дуу/эффектүүд одоогоор байхгүй.

## Папкалар

- `Assets/Scripts/` — учиш физикаси, саҳна яратиш, камера, HUD ва қурол кодлари.

Бу реал авиация тренажёри эмас, балки кейинчалик моделлар, анимациялар ва миссиялар билан кенгайтириладиган ўйин прототипидир.
